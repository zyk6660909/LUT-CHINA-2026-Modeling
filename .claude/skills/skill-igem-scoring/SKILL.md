# iGEM 三级量化评估指标体系（百分制）

对 iGEM 项目按 6 大维度、42 个三级指标打分，并应用赛道自适应权重矩阵。

## 六大维度与指标（满分分配）

- **维度1 问题定义与社会价值（20）**：痛点真实性与需求刚性 11（场景精准度 3 / 需求验证深度 4 / 现有方案痛点强度 4）；社会价值与可持续性 9（SDG 匹配 3 / 受益群体普惠性 3 / 长期社会正向价值 3）。
- **维度2 合成生物学创新与工程化设计（20）**：技术路线原创性 8（核心设计原创性 3 / 生物元件设计质量 3 / 跨学科融合深度 2）；DBTL 循环完整性 8（迭代轮次 3 / 测试方案量化 3 / 迭代闭环 2）；系统设计严谨性 4（技术链路自洽 2 / 性能目标明确 2）。
- **维度3 实验可行性与赛季交付能力（20）**：技术成熟度与难度匹配 8（核心成熟度 4 / 难度团队匹配 4）；实验方案可执行性 7（周期合理性 3 / 方法标准化 2 / 对照重复 2）；赛季成果可达性 5（核心功能验证 3 / 交付物完整度 2）。
- **维度4 落地应用与商业价值（20）**：产品与场景匹配 7（产品形态 2 / 用户需求匹配 3 / 竞品差异 2）；商业闭环 7（商业模式 3 / 市场空间 2 / 技术拓展性 2）；监管与落地路径 6（监管清晰 3 / 阶段规划 3）。
- **维度5 团队配置与资源保障（10）**：团队配置 5（学科覆盖 2 / 能力匹配 2 / 分工时间 1）；资源保障 5（实验室设备 2 / 资金 2 / 外部合作 1）。
- **维度6 生物安全、伦理与人文实践整合度（10）**：生物安全防控 4（遏制策略 2 / 操作废弃物 1 / 应急处置 1）；伦理与社会责任 3（伦理评估 2 / 利益相关方沟通 1）；HP 与项目整合度 3（反馈驱动迭代 2 / HP 活动覆盖 1）。

## 赛道自适应权重矩阵

| 赛道 | 调整 |
| --- | --- |
| Therapeutics/Diagnostics | 维度6 权重 ×1.3；维度4「监管路径」×1.5 |
| Environment | 6.1.1「生物遏制策略」升级为硬性门槛：无双重遏制直接 0 分标红 |
| Software & AI | 豁免 V4-1；维度3 湿实验指标替换为「算法可复现性/开源许可/工具普惠性」；维度4 商业闭环权重减半 |
| Foundational Advance | 维度4 权重 20 → 10，释放 10 分到维度2 |
| 其他 | 默认权重 |

## 打分规则

1. 每个指标打 0 到该指标满分的分（可一位小数）。
2. **证据链锚定**：每次打分必须引用用户原文片段；无依据时强制给 0 分并标「信息缺失」。
3. 权重归一化后总和为 100，维度得分 = 指标得分和 / 指标满分和 × 100。
4. 置信度折减：信息完整度 ≥90% → ×1.0；60-89% → ×0.8；<60% → ×0.5。
5. 可行性等级：≥85 极高 / 70-84 较高 / 55-69 中等 / 40-54 低 / <40 极低。
