# iGEM Veto 一票否决检查

对 iGEM 项目做「一票否决」前置审查。硬 Veto 命中即熔断（不评分），软 Veto 锁定流程但给出修复路径后仍可继续。

## 规则清单（15 条）

### V1 生物安全
- **V1-1 硬**：涉及 BSL-3/4 或一、二类高致病病原，且无对应实验室资质/合规来源。
- **V1-2 硬**：设计可自主传播的基因驱动，且无「营养缺陷型 + 致死开关 + 物理封装」中至少两层。
- **V1-3 硬**：计划赛季内将未灭活工程微生物投放开放环境，无封闭管控。
- **V1-4 软**：实验安全等级 > 实验室资质，且无补救管控方案。

### V2 伦理合规
- **V2-1 硬**：干预性人体试验无伦理批件。
- **V2-2 软**：活体脊椎动物实验无伦理批件或无合规场地。
- **V2-3 硬**：人类遗传资源采集/存储/处理违规且无报备。

### V3 法律与知识产权
- **V3-1 硬**：产品/技术违反《生物安全法》《药品管理法》等，如未取证宣称治疗功效、工程菌违规作食品原料。
- **V3-2 软**：使用管制品无合法资质。
- **V3-3 软**：核心技术/元件与已授权专利重合度 > 80% 且无授权。

### V4 项目真实性
- **V4-1 硬**：全程无基因工程/合成生物学改造（纯材料、纯软件、纯调研）。**赛道豁免：Software & AI、Foundational Advance。**
- **V4-2 软**：使用 iGEM 白名单外高危材料且未报备。
- **V4-3 硬**：1:1 复刻往届项目，或抄袭/虚构数据。

### V5 技术可行性
- **V5-1 硬**：核心技术违背基础科学原理，无权威文献支撑。
- **V5-2 软**：核心实验周期 > 12 个月且无分阶段规划。

## 操作步骤

1. 读取用户提交的项目输入（含赛道 track）。
2. 先识别赛道：若为 `Software & AI` 或 `Foundational Advance`，对 V4-1 应用豁免（不因无湿实验而熔断）。
3. 逐条运行检测。**注意否定上下文**：如「不涉及人体试验」「不投放开放环境」等否定表述不应触发对应规则。
4. 硬 Veto 任一命中 → 输出熔断报告并停止后续评分。
5. 软 Veto 命中 → 输出具体修复动作（如「补齐动物实验伦理批件，或改用离体模型替代」），并标注可解除后继续。
6. 全部未命中 → 输出「15 项 Veto 全部通过」。

## 输出格式

```json
{
  "id": "V2-1",
  "level": "hard",
  "triggered": false,
  "title": "干预性人体试验无伦理批件",
  "detail": "...",
  "fixPath": "..."
}
```
