# iGEM 完整评估报告生成

汇总 Veto 检查、量化打分、奖牌判定与专项奖匹配，产出结构化评估报告 JSON。

## 报告结构

1. **态势概览**：Veto 红绿灯状态、总分与可行性等级、置信度条、6 维雷达图（带往届金奖均值基准线）。
2. **指标树与证据链**：42 项三级指标红黄绿标注，点击显示 AI 打分依据（引用用户原文高亮）+ 优化建议。
3. **奖牌 Checklist**：铜/银/金三列，达标绿勾、未达标红叉 + 补齐动作。
4. **专项奖罗盘**：推荐可申报专项奖，附契合度评分与差距分析。
5. **整改后预估**：若采纳全部 P0/P1 建议，预估提分 +N 分，可达 X 等级。

## 生成流程

1. 计算信息完整度 → 置信度系数（≥90%→1.0；60-89%→0.8；<60%→0.5）。
2. 本地规则引擎快速扫描硬 Veto → 命中则直接返回熔断报告。
3. 通过则调用 Claude 四角色评估（安全合规官 / 合成生物学技术官 / 社会实践与商业官 / 主审仲裁官），无 API Key 时降级本地规则引擎。
4. 应用赛道权重矩阵与置信度折减。
5. 组装 `Report` JSON 并持久化。

## 关键约定

- 每个分数必须附「引用原文」证据；无依据给 0 分标「信息缺失」。
- 硬 Veto 熔断报告：总分 0，等级「熔断」，列出命中的硬 Veto 与修复路径。
- 专项奖契合度 0-100，附契合原因与差距分析。
- 优化建议按 P0/P1/P2 分级，P0/P1 用于估算提分。
